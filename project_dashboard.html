AI agent guidelines (primary)

Record the milestone before work, keep status current, validate before marking done, and record corrections instead of silently changing history.
  1. Create or update the milestone/job with intended scope and priority before editing files.
  2. Use in_progress while working; the file watcher records edits automatically.
  3. Run validation/tests before marking done.
  4. If a prior milestone or job was wrong, add a correction entry and mark the target corrected.
  5. Keep priority numeric (lower number = higher priority).
